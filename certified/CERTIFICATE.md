This directory records verified computational claims for the discriminant-12 Prym prototype. Scope is narrow; see each JSON file for precise statements.

## Scope

**Included.** Exact residual-0 real multiplication; geometric construction of S(1,-2); path-local dual monodromy sum enclosure under the stated error model; combinatorial identification with the known locus Omega E_12(4); Hilbert open-set path uniqueness on pure trajectories.

**Not included.** Formal bounds on individual non-tautological exponents; a new proof of Chen-Moller; continuum branch-union interval enclosures.

The almost-everywhere value sum lambda_i^+ = 8/5 on Omega E_12(4) follows from Chen-Moller once the surface is identified with that locus. The path-local interval is a consistency check on explicit combinatorial data, not a substitute for the theorem.
