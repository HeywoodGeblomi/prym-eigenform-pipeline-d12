# Track D — Statement and Reduction

## Target theorem

Inside the Prym locus of H₃(4)^odd, every Teichmüller curve of residual-0 Model A± type in the spectral class Σ=8/5 has

```text
λ₂ + λ₃ = 3/5
```

independently of the discriminant D.

## Structural reduction

| Piece | Status |
|-------|--------|
| Residual-0 ⇒ cylinder moduli mᵢ = 1 for all D | Proved |
| Gate 1 cusp weight Σ aᵢ² = (6−√3)/12 | Proved |
| EKZ ⇒ Gate 1 c_area = 18/(5π²) | Proved |
| Combinatorial cusps uniform on class | Proved (Track B) |
| C_cusps / \|χ\| independent of D | **Open** |

## Open gate

Prove that the ratio C_cusps / |χ(C_D)| is independent of D for residual-0 Model A± Teichmüller curves in the Σ=8/5 class of H₃(4)^odd.

Parallel: Nguyen (arXiv:2602.19901, arXiv:2510.23333) proved Siegel–Veech constants independent of D for ΩE_D(2,2)^odd by intersection theory on the Hilbert modular surface.

Once the ratio is constant, EKZ forces λ₂+λ₃=3/5 for every such curve, every admissible D.
