# Track D — Formal Statement

**Status: OPEN**

## Theorem target

**Claim.** Let C be a Teichmüller curve in the Prym locus of H_3(4)^odd that admits a Model A± three-cylinder decomposition and whose absolute period vector lies in the residual-0 eigenplane of real multiplication by an order of discriminant D. Suppose C belongs to the spectral class Σ=8/5.

Then the non-tautological Lyapunov exponents satisfy

λ₂ + λ₃ = 3/5

independently of the discriminant D.

In particular Gate 1 (D=12) has λ₁=1, λ₂+λ₃=3/5, Σ=8/5, and the same sum holds for every residual-0 Model A± Prym curve in the Σ=8/5 class.

## Hypotheses
1. Stratum: H(4)^odd
2. Combinatorics: Model A± three-cylinder type
3. Algebra: residual-0 real multiplication
4. Spectral class: Σ=8/5

## First theoretical lever
**Siegel–Veech / EKZ formula** on residual-0 Model A± Prym curves. If Siegel–Veech constants are combinatorial (independent of D), the sum 3/5 is uniform in D.
