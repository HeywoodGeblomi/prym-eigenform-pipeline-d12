# Note on the Lyapunov sum for residual-0 Model A± curves in H(4)^odd

**This is not a new theorem.**

Chen–Möller (Geom. Topol. 16, 2012) prove that the sum of Lyapunov exponents is non-varying on H(4)^odd and equals 8/5. Every residual-0 Model A± Prym Teichmüller curve of discriminant D lies in this component (in particular the D=12 prototype), so the sum on each such curve is 8/5. Combined with the EKZ formula one also recovers λ2+λ3=3/5 and the corresponding Siegel–Veech constant.

The short derivation is recorded here only as a literature pointer for the computational project. Authorship of the result belongs to Chen–Möller (and EKZ for the area formula).

Do not cite this repository as the source of the sum 8/5.
